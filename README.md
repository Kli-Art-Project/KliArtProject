# KLI ART PROJECT

Portofolio flayer motion, jadwal DJ, dan flayer event.

## Cara upload ke GitHub dan online lewat GitHub Pages
1. Buat repository baru di github.com (contoh nama: kli-art-project), pilih Public.
2. Klik "uploading an existing file", lalu upload SEMUA isi folder ini: index.html, folder assets, dan README.md.
3. Klik Commit changes.
4. Buka Settings > Pages. Di Source pilih "Deploy from a branch", Branch: main, folder: / (root), lalu Save.
5. Tunggu 1 sampai 2 menit. Alamat web muncul di halaman Pages: https://NAMA-GITHUB.github.io/kli-art-project/

## Struktur
- index.html : seluruh halaman web
- assets/video : 6 video flayer motion
- assets/img : flayer gambar
- assets/logo.png : logo KLI
